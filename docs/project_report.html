Different surfaces (neither strictly better)

#AspectPaper framingOur framing

Honest summary. The paper is a stronger trained model and benchmark. We are a stronger product around that model. The composition would work cleanly: take the paper's trained weights, drop them into our inference server + renderer + handoff spec, and you have a deployable product backed by paper-grade model quality. The single missing piece in our column is the trained model itself — a ~$30 cloud run we have scripted and validated locally but have not executed because we lack the real league tracking data that would justify the GPU time. That gap is commercial, not technical.
