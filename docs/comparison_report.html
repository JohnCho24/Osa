Corrections from prior report. The README I'd been citing claimed paper "ADE ~1.4 m @ 1 s" and "FDE ~2.8 m @ 4 s." Verified against §3.1 of the PDF: the 1.4 / 2.8 numbers were actually the opponent-conditioned 5 s min ADE (1.30 m) and min FDE (2.89 m), misattributed to a different horizon. The true unconditioned min ADE @ 1 s is 0.62 m. Our prior comparison oversold our novelty (row 2) by under-crediting the paper's style/league/objective conditioning surface. This report restates both honestly.

Bottom line

Research substance — architecture, trained-model quality, breadth of conditioning, event head, peer reviewPaper, decisively
Product surface — UX, server, physics, handoff, deploy automation, eval reproducibilityOsa, decisively
Stylistic / contextual conditioning (team, league, objective)Paper (we don't have it)
Coach-input conditioning (arrows, ball passes, CFG knob)Osa (paper doesn't have it)
Commercial validationNeither (paper doesn't need it; we need it badly)

The paper is a stronger trained model and benchmark. We are a stronger product around that model. The two compose well: take the paper's trained weights, drop them into our inference server + renderer + handoff spec, and the result is deployable. The single missing piece in our column is the trained model itself — a ~$30 cloud run we have scripted and validated locally but have not executed because we lack the league tracking data that would justify the GPU time. That gap is commercial, not technical.
